# KVKK - Personal Data Protection Club

Website for the **Kişisel Verileri Koruma Kulübü** (Personal Data Protection Club) at Trabzon Sosyal Bilimler Lisesi (Trabzon Social Sciences High School).

This Next.js application serves as the official website for the club, providing information and resources about personal data protection and privacy.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
